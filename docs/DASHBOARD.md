# v2.8.1 — Home command center

Home includes a refreshable music endpoint check (not global PC health), network interface and local pairing state, cached music metadata and offline download counts/storage, shortcuts to existing modules, and the existing pinned/recent tools. Reads local caches without starting a sync or downloading anything. Status refreshes on opening Home, returning from a module, app resume, or manual refresh. Unknown values show a dash. No new endpoints or backend changes. Tools remains the default landing tab. No claim of live now-playing or PC CPU metrics.
