# v2.8.0 — Neon Eclipse / Appearance Studio

Settings → Appearance Studio provides five presets, six accent swatches, glow and glass sliders, motion preference, live preview, Apply and Reset. Preferences are stored on-device under a dedicated key. The catalog and shared Material theme honor the settings; custom-painted game screens and older hardcoded module colors are not fully migrated. Glass is layered translucent-color blending, not expensive live blur. Home now includes an overview of real catalog counts. No server/API behavior changed.
